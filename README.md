# Yang Qi — Portfolio

This repository contains the source code for my professional portfolio website.

My positioning: Research Engineer working on efficient machine learning architectures, language-model training and post-training, tensor methods, and mathematically grounded machine learning.

## Website

https://yangqi-portfolio.vercel.app/

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Repository Purpose

The website highlights selected machine learning projects, research experience, and technical background.
